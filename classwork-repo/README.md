# 小小算术 · 班级作业本

单班级数学作业网站，在[第一轮需求](docs/requirements-01.md)基础上实现本次对话的题型、题量及截止时间需求（2026-11-23）：教师创建学生账号、选择题型并发布 10、20 或 50 道计算题，可选填北京时间截止时间；学生登录、保存草稿、提交和查看自动批改；教师查看逐人成绩、已交/未交人数及平均分。学生仅能访问自己的答案与成绩，数据保存在本地 SQLite。

学生也能续做已有的乘除法和混合运算作业，师生可用原账号查看原成绩。

开发遵循 [执行规则](AGENTS.md) 和 [小步提交规范](docs/commit-policy.md)。

## 启动和停止

需要 Node.js 22.13+（本机已用 22.17.0 验证）。运行服务无需安装第三方依赖，也无需配置数据库服务。

在含有 `package.json` 的项目目录打开 PowerShell，运行以下命令。

```powershell
npm start
```

浏览器打开 **http://127.0.0.1:5173**。`npm start` 启动两个独立进程：前端 5173、API 3001。终端按 **Ctrl+C** 停止两者。端口冲突时启动会退出，不会关闭其他项目的进程。

`npm run demo` 是可选的演示初始化：只补建不存在的演示学生；仅在尚无任何作业时添加第一份练习；重复执行不会清空数据或重置密码。只想从空班级开始时，首次启动可直接执行 `npm start`。

| 身份 | 账号 | 初始密码 |
| --- | --- | --- |
| 教师 | teacher | Teacher123! |
| 学生小雨 | student01 | Student123! |
| 学生小明 | student02 | Student123! |

空库首次运行时自动建立教师账号，表中的两个演示学生由 `npm run demo` 建立。教师可在「学生名单」中继续创建账号。

## 使用顺序

1. 用教师账号登录，在「学生名单」填写姓名、账号及至少 8 位密码；把账号密码告知该学生。
2. 在「作业与成绩」填写作业名称，选择一种题型（20 以内加减、20 以内乘除、100 以内混合运算）和题量（10、20、50 道），可选填「截止时间（北京时间）」后发布，自动生成全班同一套题；点开作业查看进度。
3. 教师退出后，用学生账号登录，打开「我的作业」。可部分作答后点「保存草稿」，刷新或下次登录可继续。
4. 完成本份作业全部题目，点「提交作业」并确认；立即显示总分、每题对错与正确答案。提交后锁定答案。
5. 换回教师账号，打开该作业并点「刷新成绩」，查看每位学生的成绩和统计。

例如要设为“明晚八点前交”，在日期时间控件选择明天的日期和 20:00；不填则不限时。设备使用其他时区时，输入与展示仍按北京时间（Asia/Shanghai，UTC+08:00）处理。

草稿为手动保存，页面会提示未保存的修改，离开或退出前会确认。多位学生可使用不同浏览器/独立会话同时操作；同一浏览器的普通标签页共享登录会话。

## 业务规则

- 每次发布选择一种题型和 10、20 或 50 道题，默认是 10 道「20 以内加减」。加减、乘除各占一半；混合题包含两步运算，整份覆盖四则。算式互不重复，所有操作数、中间结果和答案均为对应范围内的非负整数，除法整除且无零除数。
- 历史作业沿用保存的原题。「20 以内加减」和「20 以内乘除」接受 0–20 的整数，「100 以内混合运算」接受 0–100 的整数。师生看到相同的算式，例如 `24 ÷ (12 ÷ 3)`。
- 满分 100，按答对题数 ÷ 总题数 × 100 计分（10/20/50 题每题分别 10/5/2 分）；例如 20 题答对 19 题得 95 分；提交前不返回标准答案；评分和权限校验均由 API 执行。
- 草稿允许留空，提交前须填完本份作业所有题目。提交后锁定，回看时按原答案逐题批改，教师汇总取已保存的分数。
- 截止时间必须晚于发布时刻。到点（含截止的这一刻）后，未交学生不能提交，但仍可保存草稿，教师统计为未交，不参与平均分。已交学生可照常回看成绩，原答案与分数锁定。是否逾期由后端时钟在收齐请求内容并校验后判断，截止前开始发送但到点后才收齐的提交也会拒绝。
- 作业面向全班，新增学生也能完成未截止或不限时的历史作业；已截止作业仅能保存草稿。人数按当前名单统计；平均分仅计算已提交学生，没有提交时显示「—」。

## 数据与配置

数据默认在 `data/classwork.sqlite`，账号密码使用带独立盐的 scrypt 哈希，会话保存在数据库并使用 HttpOnly、SameSite Cookie。账号、作业（含题型与截止时间）、草稿、成绩、未过期会话均可在重启后恢复。首版旧库启动时仅补充可空的 category 和 due_at 列，历史题量以保存的原题为准，历史题目、答案和分数不重写；旧作业没有截止时间时继续不限时。`data/` 不进入 Git；备份时先停止服务，再复制整个 `data` 目录，恢复时也先停服务。

要复核已有班级，请把一致性备份的工作副本放到本项目，例如 `data/review.sqlite`，在应用目录运行以下命令。使用原账号密码登录即可。新保存的草稿与提交写入这份副本。

```powershell
$env:DB_PATH = (Resolve-Path -LiteralPath 'data/review.sqlite').Path
npm start
```

可通过当前终端的环境变量设置独立资源：

```powershell
$env:WEB_PORT = "5174"
$env:API_PORT = "3002"
$env:DB_PATH = "data/another-class.sqlite"
$env:TEACHER_PASSWORD = "YourOwnPassword123!"
npm start
```

`TEACHER_PASSWORD` 只在数据库第一次创建教师时生效，已有密码不会被覆盖。默认仅监听本机 127.0.0.1。本轮没有外网/局域网发布，也未添加 HTTPS、多班级、重交、删除学生和密码重置。

前后端可分别启动：在两个终端运行 `npm run start:api` 与 `npm run start:web`；端口配置需一致。前端为独立静态服务，使用 `/api` 代理调用后端 JSON API。前端没有数据库访问能力，后端不提供页面文件。

## 验证

```powershell
npm ci --cache .runtime/npm-cache
npm run check
npm test
```

只有测试需要 jsdom 开发依赖，锁文件固定依赖版本。检查和测试分别退出码为 0 后才视为通过。测试使用自动清理的独立临时数据库，不改动演示数据。

- `tests/api.test.mjs`：真实 HTTP 登录、教师建号/发布、草稿、权限隔离、评分、人数/平均分、重启持久化、延迟请求不可覆盖已交结果、退出与会话过期；新增三种题型 × 三档题量的生成/提交/计分校验、12/20 草稿重启恢复、截止前 1 毫秒/恰好截止/跨点慢请求、逾期草稿和已交回看。
- `tests/ui.test.mjs`：在 jsdom 中执行实际页面代码，通过真实前端代理和 API 完成表单流程、错误提示、断网重试、草稿刷新恢复、确认提交、逐题反馈、教师统计刷新及账号切换隔离；也验证静态资源和路径限制；新增题型题量表单、20 题答对 19 题显示 95 分、北京时间日期输入/展示、页面到点禁交且保留答案、客户端时钟慢时的服务端拦截及逾期草稿断网重试。

INC-001 的回归使用 1 名教师、3 名学生、3 份作业、6 条已提交记录和 1 份草稿。题目及独立的预期答案见 [合成班级数据](tests/history-fixture.mjs)。在应用目录执行以下命令，可单独重跑迁移 API 和师生页面流程。

```powershell
node --experimental-sqlite --test --test-name-pattern=INC-001 tests/api.test.mjs tests/ui.test.mjs
```
