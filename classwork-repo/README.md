# 小小算术 · 班级作业本

多班级数学作业网站，在[第一轮需求](docs/requirements-01.md)基础上实现本次对话的题型题量、截止时间，以及个人限时、知识点难度、多班级、名单导入、当前班搜索、练习月历、学生原卷和个人练习记录需求（2026-11-24）：教师创建学生账号、选择题型并发布 10、20 或 50 道计算题，可选填北京时间截止时间和个人限时；学生登录、保存草稿、提交和查看自动批改；教师按班查看月历、逐人成绩、已交/未交人数及平均分，逐题回看学生原卷并筛选个人练习记录。学生仅能访问自己的答案与成绩，数据保存在本地 SQLite。

学生也能续做已有的乘除法和混合运算作业，师生可用原账号查看原成绩。

开发遵循 [执行规则](AGENTS.md) 和 [小步提交规范](docs/commit-policy.md)。

## 启动和停止

需要 Node.js 22.13+（本机已用 22.17.0 验证）。首次使用或更新后先安装锁定的依赖；运行时读取 Excel 名单需要 read-excel-file 和 unzipper-esm，无需配置数据库服务。

在含有 `package.json` 的项目目录打开 PowerShell，运行以下命令。

```powershell
npm ci --cache .runtime/npm-cache
npm start
```

浏览器打开 **http://127.0.0.1:5173**。`npm start` 启动两个独立进程：前端 5173、API 3001。终端按 **Ctrl+C** 停止两者。端口冲突时启动会退出，不会关闭其他项目的进程。

`npm run demo` 是可选的演示初始化：只补建不存在的演示学生；仅在尚无任何作业时添加第一份练习；重复执行不会清空数据或重置密码。只想从空班级开始时，首次启动可直接执行 `npm start`。

| --- | --- | --- |
| 教师 | teacher | Teacher123! |
| 学生小雨 | student01 | Student123! |
| 学生小明 | student02 | Student123! |

空库首次运行时自动建立教师账号，表中的两个演示学生由 `npm run demo` 建立。教师可在「学生名单」中继续创建账号。

## 使用顺序

1. 用教师账号登录，在「学生名单」创建班级（原有班级可修改名称），选择当前班级，再填写学生姓名、账号、至少 8 位密码和所属班级；把账号密码告知学生。也可在名单的「所在班级」调整已有学生归属。
2. 在「作业与成绩」填写作业名称，选择一种题型（20 以内加减、20 以内乘除、100 以内混合运算）和题量（10、20、50 道），可选填「截止时间（北京时间）」和个人限时，勾选一个或多个接收班级后发布；同一份作业向所选班级提供完全相同的题目。点开作业后切换班级查看各班进度。
3. 教师退出后，用学生账号登录，打开「我的作业」。可部分作答后点「保存草稿」，刷新或下次登录可继续。
4. 完成本份作业全部题目，点「提交作业」并确认；立即显示总分、每题对错与正确答案。提交后锁定答案。
5. 换回教师账号，打开该作业并点「刷新成绩」，切换班级查看各班每位学生的成绩、已交/未交人数和平均分。

例如要设为“明晚八点前交”，在日期时间控件选择明天的日期和 20:00；不填则不限时。设备使用其他时区时，输入与展示仍按北京时间（Asia/Shanghai，UTC+08:00）处理。

个人限时可留空，或填写 1–1440 的整数分钟。限时作业先显示准备说明，第一次点击「开始作答」才显示题目并记录个人起点；倒计时连续运行，刷新或重新登录不重置。个人到期和全班截止取较早时刻，到点仍能保存草稿，未交仍计为未交。普通不限时作业保留原先直接作答流程。

草稿为手动保存，页面会提示未保存的修改，离开或退出前会确认。多位学生可使用不同浏览器/独立会话同时操作；同一浏览器的普通标签页共享登录会话。

## 批量导入学生

在「学生名单」先选择当前班级，下载页面提供的 [Excel 样例](frontend/student-roster-template.xlsx)，用本班名单替换示例行，再选择文件并点「导入当前班级」。支持 .xlsx（只读取第一个工作表）和 UTF-8 CSV，第一行须为“学号、姓名”两列；每次最多 500 名学生，文件不超过 512 KB。

- 学号必须作为文本填写，样例前 500 行已设置文本格式。00123 会按原字符串保存，账号和初始密码均为 00123；姓名相同、学号不同可以分别建立账号。学号支持 1–32 位字母、数字、下划线和短横线，姓名 1–30 字。导入后若学生填写登录密码，也须保留开头的零。
- Excel 数字学号会逐行提示改为文本，以免把已经丢失前导零的数字当成正确学号；单纯修改显示格式不能恢复已丢失的零，请核对原始学号。CSV 也须在保存前保留原始学号，推荐使用 Excel 样例。
- 有效行导入所选班级，空学号、空姓名、文件内重复学号、全系统已有账号或其他无效行均跳过，并在页面列出文件行号、学号、姓名和原因。文件内重复学号涉及的各行全部跳过。完全空行忽略，表头或文件格式错误时整份不导入。
- 导入只新增账号，不修改已有账号的姓名、密码、班级、答案或成绩。重复提交文件只会提示账号已存在；并发请求也不能覆盖已建立账号。导入结果显示后会刷新当前班完整名单。

## 当前班级搜索

导入后可在名单上方按姓名或学号搜索，支持部分匹配。两个同名学生分别展示对应的学号；显示人数为“匹配人数 / 本班总人数”，不影响作业统计。搜索只在当前班级的已加载名单中进行，换班会保留搜索词并改搜新班，旧班结果不会混入；点「清空搜索」或清空输入框即可恢复该班全名单。搜索时不会清掉已选择的待导入文件。成功导入后自动清空筛选，展示当前班完整名单便于核对。

## 教师练习月历

教师登录后点「练习月历」，选择当前班级；默认打开服务端北京时间的当前月，可用「上月」「下月」或月份输入框切换，也可点「回到本月」。月历以周一为一周起点，每个日期显示当天发布的练习份数，点击日期查看当天的作业。没有练习的日期也可查看。

作业按保存的发布日期换算为北京时间后归入日期，截止时间在作业卡片上另外显示。例如周二发布、周四截止的练习放在周二。同一天发布的多份练习分别展示本班已交人数、未交人数和平均分；平均分只计算本班已交学生，无人提交显示「暂无均分」，已交均分为 0 则显示 0。

点击作业卡片进入现有成绩明细，「返回练习月历」会保留班级、月份和日期。在月历换班保留当前月份和日期，只显示新班的作业与统计；明细页换班后返回月历也使用新班。已选的班级、月份和日期写在页面地址中，刷新仍可回到对应视图。需要更新提交进度时点「刷新月历」。本功能只读取原作业和成绩，不修改历史题目、草稿或分数，也不增加数据库迁移。

## 查看学生原卷和个人记录

在教师的班级成绩表中点击学生姓名，可逐题查看保存的原题、该生当时填写的答案、正确答案和对错，页头保留原分数。已提交的答案只读。只保存草稿或尚未保存答案的学生也能打开，页面明确标注「未交、未评分」，空题显示「未填」；草稿不评对错、不算成绩，展示最后一次保存时间，不包含学生尚未保存的修改。教师查看不会替学生开始计时、提交或修改答案。截止后仍能查看已交原卷及保存的草稿。

在「学生名单」选班并点击姓名，进入该生「练习记录」；同名学生可凭学号 / 账号区分，记录页也能切换当前班的学生。可填写开始和结束日期、选择「知识点 / 练习内容」后点「查询记录」，日期和知识点可组合筛选，任一条件可留空。日期按北京时间的发布日期查询，起止日均包含，与提交日、截止日无关。例如查看上周布置的乘除练习，选择上周一到周日以及「20 以内乘除」。点「清空筛选」恢复全部记录。

每条记录显示作业名、发布日期、知识点、提交状态和分数，点「查看原卷」进入该学生的原卷，返回时保留班级、学生和筛选条件，刷新也保留。混合知识点按发布时保存的配置匹配；旧作业没有细分配置时显示「未记录细分知识点」，仍可按三种练习题型查询。换班只列出新班学生的记录，保留筛选条件并默认选择新班第一名学生；空班显示加入学生的提示。升级前的历史作业沿用原题、原草稿和原成绩，转班学生可在个人记录中查看这些保留的旧作业，原卷链接使用原班历史成绩名单。

## 业务规则

- 每次发布选择一种题型和 10、20 或 50 道题，默认是 10 道「20 以内加减」。加减、乘除各占一半；混合作业可选择 1–6 年级、已学知识点和基础/提高难度。知识点包括连加连减、连乘连除、先乘除后加减、小括号；一年级可选加减链，二年级起可按本班已学进度勾选其余内容。基础为 2 步，提高为 3 步，只使用所选知识点，不靠扩大数值范围加难。算式互不重复，所有操作数、中间结果和答案均为对应范围内的非负整数，除法整除且无零除数。新混合题还排除加减 0、乘 0/1、除 1、同数相除，以及相邻两步直接抵消的形式。
- 历史作业沿用保存的原题。「20 以内加减」和「20 以内乘除」接受 0–20 的整数，「100 以内混合运算」接受 0–100 的整数。师生看到相同的算式，例如 `24 ÷ (12 ÷ 3)`。
- 满分 100，按答对题数 ÷ 总题数 × 100 计分（10/20/50 题每题分别 10/5/2 分）；例如 20 题答对 19 题得 95 分；提交前不返回标准答案；评分和权限校验均由 API 执行。
- 草稿允许留空，提交前须填完本份作业所有题目。提交后锁定，回看时按原答案逐题批改，教师汇总取已保存的分数。
- 截止时间必须晚于发布时刻。到点（含截止的这一刻）后，未交学生不能提交，但仍可保存草稿，教师统计为未交，不参与平均分。已交学生可照常回看成绩，原答案与分数锁定。是否逾期由后端时钟在收齐请求内容并校验后判断，截止前开始发送但到点后才收齐的提交也会拒绝。
- 新作业只向所选班级学生可见，列表、题目、开始、草稿与提交接口均检查班级权限。多班同卷只保存一套题；教师在作业页切换班级，人数按该班当前名单统计，平均分只计算该班已交学生。未选班级无法访问该作业。新加入班级的学生可看到该班历史作业，截止限制照常生效。
- 调整学生班级会改变新作业的可见范围及按当前名单的统计，已存答案、成绩不删除。升级前已有的全部学生与作业归入「原班级」，可改名；为保留旧数据的连续使用，升级前学生以后分到其他班，仍能续做和回看升级前作业。这些旧作业的成绩继续在原班级的历史报告中显示。

## 数据与配置

数据默认在 `data/classwork.sqlite`，账号密码使用带独立盐的 scrypt 哈希，会话保存在数据库并使用 HttpOnly、SameSite Cookie。账号、作业（含题型与截止时间）、草稿、成绩、未过期会话均可在重启后恢复。启动时按需补充题型、截止、限时及练习配置字段，并在事务中建立班级和旧班学生的历史作业关联；历史题量以保存的原题为准，历史题目、答案和分数不重写；已有 difficulty（basic/advanced/空）和 question_count 字段原样保留，不依难度重新出题，读取题量以实际保存的题目数量为准；旧作业没有截止时间时继续不限时。`data/` 不进入 Git；备份时先停止服务，再复制整个 `data` 目录，恢复时也先停服务。

要复核已有班级，请把一致性备份的工作副本放到本项目，例如 `data/review.sqlite`，在应用目录运行以下命令。使用原账号密码登录即可。新保存的草稿与提交写入这份副本。

```powershell
$env:DB_PATH = (Resolve-Path -LiteralPath 'data/review.sqlite').Path
npm start
```

可通过当前终端的环境变量设置独立资源：

```powershell
$env:WEB_PORT = "5174"
$env:API_PORT = "3002"
$env:DB_PATH = "data/another-class.sqlite"
$env:TEACHER_PASSWORD = "YourOwnPassword123!"
npm start
```

`TEACHER_PASSWORD` 只在数据库第一次创建教师时生效，已有密码不会被覆盖。默认仅监听本机 127.0.0.1。本轮没有外网/局域网发布，也未添加 HTTPS、重交、删除学生、删除班级和密码重置。

前后端可分别启动：在两个终端运行 `npm run start:api` 与 `npm run start:web`；端口配置需一致。前端为独立静态服务，使用 `/api` 代理调用后端 JSON API。前端没有数据库访问能力，后端不提供页面文件。

教师只读接口：GET /api/assignments/:assignmentId/students/:studentId?classId=1 按该班成绩名单读取学生原卷和最后一次保存的答案，已交返回逐题对错与原分数，草稿返回正确答案但不评对错、不计分。GET /api/students/:studentId/history?classId=1&from=2026-11-16&to=2026-11-22&topic=mul-div-20 查询当前班学生的练习记录；日期范围为北京时间发布日期，起止日均包含且可单独留空，topic 可按三种题型或已记录的混合知识点筛选。历史未记录细分知识点的作业仍可按题型查询。转班学生保留的升级前作业仍可查询并回到原班历史成绩名单。两个接口仅供教师使用，不改写题目、草稿、成绩或个人计时起点。

tests/records.test.mjs 验证教师逐题读取 80 分原卷、草稿 / 未保存状态、正确答案为 0、50 题草稿完整读取、按北京日期的午夜边界和知识点组合筛选、班级和角色权限，以及旧库原题 / 原草稿 / 原成绩不变。页面测试覆盖成绩姓名入口、名单入口、同名学生切换、日期与知识点查询、50 题原卷、空班、空结果、清空筛选、刷新与往返保留条件、断网重试及跨班拦截。

本轮在内置 Chromium 中使用独立合成数据，实际从成绩姓名打开 80 分原卷，核对两题错误、学生答案和正确答案；查看截止后的草稿，确认「未交、未评分」、答案 0 和空题。再按 2026-11-16 至 2026-11-22 查询乘除练习和「先乘除后加减」，打开 50 题草稿并返回、刷新保留条件；切换二班只显示该班学生与成绩。375 像素视口下筛选和原卷均无页面横向溢出。完整 54 项测试在默认时区与 America/Los_Angeles 下通过。
