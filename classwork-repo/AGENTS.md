# 专属开发会话约定

在 `classwork-repo/` 按本轮提示词实现功能，维护应用代码、依赖、测试和启动说明。Git 的初始化、暂存、提交及回滚统一由上一级 phase2 审查会话负责，应用文件直接保存在本目录。

交付时在会话回复中写清楚以下内容，供用户转交审查会话。

- 本轮编号、解决的问题、实际修改的文件，以及用户能观察到的行为变化。
- 影响实现的选择与理由。发生返工时，写明失败现象、修正方式和重试结果。
- 可复现的运行命令或操作、测试输入、实际输出，以及仍需用户确认的事项。

需求澄清和补充指令保留原话。跨轮次的决策、架构、需求和计划由审查会话整理到[项目资料](../docs/resource/README.md)。
