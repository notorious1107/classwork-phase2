## 版本与回滚

审查会话在 `classwork-phase2/` 一起提交应用文件和对应文档。开发会话在 `classwork-repo/` 的独立仓库按[开发约定](classwork-repo/AGENTS.md)提交和自测。两边使用同一份应用文件。新检出工作区时，按[版本管理约定](docs/resource/decisions/001-版本管理与会话分工.md)初始化开发仓库。

以 `SETUP-001` 为例，在本目录运行 `git log --oneline --grep=SETUP-001` 定位该轮提交，用 `git show <提交号>` 检查内容。需要撤销时，审查会话确认目标提交和当前工作区状态后，用 `git revert <提交号>` 生成一条撤销记录。如果一轮包含多次提交，按从新到旧的顺序逐个撤销。回滚后复查进度页与应用状态。
