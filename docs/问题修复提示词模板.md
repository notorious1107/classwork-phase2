# 问题修复提示词模板

转述问题时，像给同事发一条消息。说清楚谁在做什么、哪一步出了问题、当时看到了什么。写到对方能认出这个问题就够了，原因和修法留给开发者判断。

## 可以直接套用的写法

> 收到［学生／老师］反馈，［当时在做什么］。［做了哪一步］后，［页面实际显示了什么，或哪件事做不了了］。

如果是自己体验时发现的，就用“我用学生账号……”或“我在老师端……”开头。如果某个条件决定问题会不会出现，比如只在作业截止后遇到，就把它写进经过里。现象本身不好理解时，再补一句当时以为会看到什么。

## 例子

> 我在老师端出了一份综合练习，只选了加减和乘除。难度切到“提高”后，旁边写着“混合题实际运算 3 步”。我以为自己多选了题型，点开预览才看到，卷子里确实只有加减和乘除。

同一条消息里有几个独立问题时，用“1、”“2、”分开写。一个问题用一小段话就够了。
