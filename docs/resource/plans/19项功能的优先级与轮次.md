# 19 项功能的优先级与开发轮次

**2026-11-24 排期更新。** 用户选定[个人作答限时、混合题难度与平行班](../../开发记录/INC-003.md)作为 INC-003。下表保留 11 月 23 日的原建议。草稿保护另候排期，原建议中难度分档的混合题部分提前到本轮。

2026-11-23。用户已指定下一轮为 **INC-002 · P2-FR-02**。其余 17 项是建议顺序，后续可根据内网试用结果调整。表中序号对应[原始 19 项功能清单](../requirements/三项目全量测试对照-当前功能缺口.md)从上到下的条目，便于对照旧版实测。

| 建议轮次 | 优先级 | 同轮交付的功能 | 前置条件与合并理由 |
| --- | --- | --- | --- |
| **INC-002　按要求发布作业** | **P0 · 下一轮** | ① 选择新卷的题型和题量<br>⑤ 设置截止时间并拦截迟交 | 已有单班级发布、草稿与批改。用“20 题乘除卷，明晚截止”一次验证发布、续答、按题量计分和到期处理。[验收条件与提示词](../../开发记录/INC-002.md) |
| INC-003　草稿不丢失 | P1 · 保护学生作答 | ⑧ 两个页面编辑同卷时处理冲突<br>⑨ 原账号重登后找回未保存输入<br>⑦ 停笔自动保存、保存后离开 | 长卷增加重填成本。轮内先处理草稿版本和原账号恢复，再启用自动保存。用同一份草稿验收旧页、新页、重登与离开时最终保留的答案。 |
| INC-004　交卷与教师查卷 | P1 · 完善日常教学 | ⑩ 提示漏答题数并允许确认交卷<br>⑪ 从成绩表打开某个学生的已交答卷<br>⑫ 查看某个学生已保存的草稿内容 | 复用 INC-002 的实际题量、分值和截止判断。先区分“交了但漏答”和“只存草稿”，再让教师从同一成绩表打开两种记录，核对原答、状态和分数。教师可读草稿是此轮建议新增的可见范围。 |
| INC-005　班级账号维护 | P1 · 支持内网试用 | ⑱ 学生自助改密、教师重置学生密码<br>⑲ 在学生名单中搜索 | 只依赖现有账号和名单。教师查找同名学生、按账号核对并重置密码，可用一个实际场景验收。若试用首先遇到无法登录，可把整轮提前。 |
| INC-006　预览后确认发布 | P2 · 降低错发、重发 | ④ 整卷预览、换一套再发布<br>⑥ 发布结果不明时安全重试 | 依赖 INC-002 的生成规则与发布入口。两项共同要求认准教师最后选中的那一份卷。验收从换卷预览一直走到发布成功但回执丢失后重试，学生只看到选定卷一次。 |
| INC-007　扩展出题组合 | P2 · 丰富教学内容 | ② 按基础、提高两档出题<br>③ 一张卷组合多个知识点 | 依赖 INC-002 的三类题目和分值。先验证每类的两档规则，再将所选知识点的题量均分，按同一难度生成。验收时核对各类题数之和、难度和总分。预览可用于检查整卷。 |
| INC-008　查询学习历史 | P2 · 回查多次作业 | ⑬ 按条件查询学习历史<br>⑭ 查看班级跨作业总平均分 | 复用 INC-004 的原答入口。按难度查询依赖 INC-007 的分档数据，旧卷可按“历史未分档”查回。列表和均分使用同一查询范围，均分按实际已交份数加权。 |
| INC-009　个人错题与订正 | P2 · 支持学生复习 | ⑯ 汇集多份作业的个人错题本<br>⑰ 错题再练、订正记录和分步解析 | 依赖 INC-004 区分首次错答和漏答。先能定位某卷某题，再对原题隐藏答案、独立记每次练习，回查首次成绩。可独立于班级历史查询和分析交付。 |
| INC-010　班级常错题分析 | P3 · 积累班级数据后做 | ⑮ 找出班级常错题并追到原答 | 需要 INC-004 的逐题原答和漏答口径，可复用 INC-007 的知识点、难度及 INC-008 的筛选。单独验收跨卷分母、人数和原答是否对应。数据来自首次正式提交，无需等待学生完成订正。 |

**本轮边界。** 一份新卷选一个知识点。“100 以内四则混合”是一种题型，和“把几种知识点的题按份额拼在同一卷”是两项不同的教师操作。难度分档、多知识点拼卷、整卷预览、安全重试和带漏答交卷均已在表中另有轮次。

**可以调整的顺序。** INC-003 和 INC-004 分别解决保存与批阅，排在前面是因为学生会开始做更长的卷。账号维护可穿插。预览先于难度与多选是为了让教师能在发布前看到整卷效果，三类出题本身已经由 INC-002 提供。班级常错题分析可以和个人订正分别安排，两者只共享原始作答数据。

## INC-003 验收场景

| 验收场景 | 操作与预期 |
| --- | --- |
| 不同学生的个人限时 | 给一份作业设 20 分钟。两名学生于 19:00 和 19:10 开始，各自看到剩余时间，分别在 19:20 和 19:30 到期。刷新和重新登录沿用第一次开始的时刻。 |
| 与统一截止配合 | 同一示例加上 19:25 截止，第二人只能做到 19:25。服务端在到点时停止接收首次交卷，仍可保存草稿，计为未交。留空个人时长的作业继续沿用原截止规则。 |
| 混合题按所学内容和难度生成 | 选择年级、该年级已学知识点和基础档，复算题面并核对运算范围。换成已学括号的提高档，检查括号与有效步骤确实影响解法，题面和答案一致。新题保持 100 以内整数、除法整除，排除乘 1、除 1、加减 0 或乘 0 等可跳过的步骤。历史卷仍能按原题查看、判分。 |
| 平行班的发布范围 | 一班、二班各建名单。只给一班发布时，仅一班学生能打开作业。将同一份练习发给两班，两班学生看到同一套题，教师能按班查看学生进度。原班的账号、作业、草稿和成绩继续可用。 |
| 分班统计 | 一班三人，两人分别得 80、100 分，一人只存草稿。一班应显示 2 已交、1 未交、均分 90。二班两人均未交，显示 0 已交、2 未交、均分暂无。切班后学生明细与各自人数一致。 |
