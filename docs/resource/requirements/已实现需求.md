# 已实现需求表

最近同步于 2026-11-24，对应 [INC-002]，应用版本 `6c4d794`。下表按当前单班级系统中师生能完成的操作整理。各项均有技术验证记录，混合题的出题质量仍有一项待修正，内网师生试用待验收。

| 使用者 | 需求 | 当前可观察的行为与边界 | 验证依据 |
| --- | --- | --- | --- |
| 师生 | 用自己的账号登录 | 教师登录后可管理名单、发布作业和查看全班成绩。学生登录后只能读写本人的作答、查看本人成绩。退出后须重新登录。 | [MVP-001] |
| 教师 | 为学生开通账号 | 在「学生名单」逐人填写姓名、登录账号和初始密码。名单显示姓名和账号，同名学生可用不同账号区分，重复账号会被拒绝。 | [MVP-001] |
| 教师 | 选择题型和题量发布作业 | 填写作业名称，每份从 20 以内加减、20 以内乘除、100 以内四则混合中选一种，题量可选 10、20 或 50 道。只填名称时发布 10 道加减题，无截止时间。 | [INC-002] A1、A2 |
| 师生 | 全班使用同一套题 | 发布后教师可展开整卷，学生看到相同题面和题序，刷新或重登后仍是原卷。卷内算式去重。加减卷、乘除卷的两种运算各占一半，操作数和结果均为 0–20 的整数，除法整除且除数非零。 | [INC-002] A2、A6 |
| 师生 | 练习两步混合运算 | 每题含两种运算，整卷覆盖加减乘除。括号体现运算顺序，操作数、中间值和结果均为 0–100 的整数。**出题质量部分通过**，实测出现过 `83 ÷ (83 × 1)`，其中乘 1 的步骤可省。 | [INC-002] A2 |
| 教师 | 为全班设置交卷截止时间 | 可留空，或按北京时间选择一个未来时刻。师生看到同一截止时间。服务器收齐并校验答案时须早于该时刻，恰好到点或更晚均拒绝首次交卷。 | [INC-002] A1、A4 |
| 学生 | 找到要做的作业 | 「我的作业」按发布先后从新到旧排列，显示题型、题量、截止时间和本人的作业状态。新加入班级也能打开以前发布的作业，沿用该卷原有截止时间。 | [MVP-001]、[INC-002] A4、A6 |
| 学生 | 分次作答并保存草稿 | 可跳题，页面按实际题量显示已答进度，填 0 计为已答。手动保存后，刷新或下次登录可接着写。带未保存修改离开时有确认提示，断网保存失败后可在原页重试。截止后仍可保存和重开草稿，教师端计为未交。 | [首版页面验证]、[INC-002] A3、A4 |
| 学生 | 确认交卷并查看批改 | 须答完全部题目并确认才能交卷。交卷前隐藏标准答案，交卷后立即显示总分、自己的答案、逐题对错和正确答案。满分 100，10、20、50 题每题分别占 10、5、2 分，例如 20 题答对 19 题得 95 分。 | [MVP-001]、[INC-002] A3 |
| 学生 | 回看首次提交结果 | 提交后答案锁定，迟到的草稿或重复提交都不能覆盖原答案、成绩和提交时间。截止后仍可回看批改。 | [首版接口验证]、[INC-002] A4 |
| 教师 | 查看每份作业的完成情况和成绩 | 在「作业与成绩」查看单份作业的已交、未交人数和平均分。打开作业可按姓名和账号查看状态、提交时间和得分，点击「刷新成绩」取得最新结果。应交人数取当前班级名单，均分只计已交学生，无人提交时显示「—」。 | [MVP-001]、[INC-002] A3、A6 |
| 师生 | 接着使用迁入的历史作业 | 原账号、原题和题序、已存答案、提交时间及成绩可继续使用。历史乘除和嵌套混合题按原算式显示并判分，含答案 27 的混合草稿可续答。缺少题型时按题面识别，已有截止时间继续生效，缺少截止时间的旧卷可照常交卷。 | [INC-001]、[INC-002] A5 |
| 师生 | 服务重启后继续使用 | 重启后账号、未过期的登录会话、已发布作业的配置和题序、已存草稿及成绩均可恢复。 | [首版接口验证]、[INC-002] A4、A5 |
