| 使用者 | 需求 | 当前可观察的行为与边界 | 验证依据 |
| --- | --- | --- | --- |
| 师生 | 用自己的账号登录 | 教师登录后可管理名单、发布作业和查看全班成绩。学生登录后只能读写本人的作答、查看本人成绩。退出后须重新登录。 | [MVP-001] |
| 教师 | 管理班级与学生账号 | 可创建班级、改班名，在「学生名单」按班逐人开通账号或调整学生归属。同名学生可用不同账号区分，重复账号会被拒绝。 | [MVP-001]、[INC-003] |
| 教师 | 选择题型、题量和接收班级 | 选择 20 以内加减、20 以内乘除、100 以内混合，或组合其中两三类；题量可选 10、20、50，接收班级可多选。预览满意后确认发布。 | [INC-002]、[INC-003]、[INC-008] |
| 师生 | 给指定班级使用同一套题 | 单班发布仅该班学生可见。多班发布共用题目和题序，刷新或重登仍是原卷。卷内算式去重。加减卷、乘除卷的两种运算各占一半，操作数和结果均为 0–20 的整数，除法整除且除数非零。 | [INC-002] A2、A6，[INC-003] |
| 师生 | 按已学知识点和难度做混合题 | 教师选择 1–6 年级，再勾选本班学过的内容。一年级可选加减连算，二年级起还可选乘除连算、先乘除后加减、小括号。基础两步、提高三步，数值及中间结果均在 0–100 内，除法整除；生成时排除加减 0、乘 0 或 1、除 1 等可省步骤。 | [INC-003]；[INC-002] A2 为修正前实测 |
| 教师 | 为全班设置交卷截止时间 | 可留空，或按北京时间选择一个未来时刻。师生看到同一截止时间。服务器收齐并校验答案时须早于该时刻，恰好到点或更晚均拒绝首次交卷。 | [INC-002] A1、A4 |
| 师生 | 按每份作业设置个人限时 | 教师可留空或设置 1–1440 整数分钟。限时卷首次点「开始作答」才显示题目并启动个人倒计时。刷新、重登和服务重启沿用起点，与全班截止取较早者。到点拒绝首次交卷，仍可存草稿并计为未交。 | [INC-003] |
| 学生 | 找到要做的作业 | 可提交作业按本人实际截止时间从早到晚排列，无期限的放最后。首页单列已截止未交、已提交，到时自动更新。个人计时未开始时按全班截止排序。教师成绩表也逐人显示限时到点状态。 | [MVP-001]、[INC-002] A4、A6，[INC-003]、[INC-013] |
| 学生 | 分次作答并保存草稿 | 可自动、手动或点“保存并离开”存稿。一题越界时先存其他题，确认离开后该题保留上次有效值。登录失效时，同浏览器原账号可恢复待同步输入。已同步答案可换设备续写，双页冲突可选择版本。截止后仍可保留草稿。 | [INC-002]、[INC-003]、[INC-010]、[INC-011] |
| 学生 | 确认交卷并查看批改 | 交卷前提示空题数量并按顺序列出题号。点题号可直达输入框，补答后重新计算，0 算已答。也可确认按现有答案交卷，按全卷计分，漏答计入错题本和学情统计。 | [INC-002]、[INC-007]、[INC-009]、[INC-010]、[INC-012] |
| 学生 | 回看首次提交结果 | 提交后答案锁定，迟到的草稿或重复提交都不能覆盖原答案、成绩和提交时间。截止后仍可回看批改。 | [首版接口验证]、[INC-002] A4 |
| 教师 | 按班查看每份作业的完成情况和成绩 | 按作业记录的班级名单查看已交、未交、逐人成绩与已交均分。转班后原班成绩和个人原卷可回查，多班同卷每人只计一次。旧多班卷按升级时可得信息恢复。无法归班的原卷仍可由个人记录打开。 | [MVP-001]、[INC-002] A3、A6，[INC-003]、[INC-015] |
| 师生 | 接着使用迁入的历史作业 | 原账号、题目、题序、已存答案、提交时间及成绩继续有效。历史乘除和嵌套混合按原算式显示并判分。保留原难度字段（含空值）及已有题量字段，显示题量以原题数为准。 | [INC-001]、[INC-002] A5，[INC-003] |
| 师生 | 服务重启后继续使用 | 重启后账号、未过期的登录会话、已发布作业的配置和题序、已存草稿及成绩均可恢复。 | [首版接口验证]、[INC-002] A4、A5 |
| 师生 | 改密码或按学号重设 | 学生验证原密码后可更改，教师可按班和账号重设指定学生；同名的其他人可继续使用原密码。 | [INC-010] |
| 教师 | 跨作业汇总学情、定位常错题 | 可按班和北京时间发布日期区间看练习、已交、未交和按已交份数计算的整体均分；点开常错题查逐人原答，订正不改首次统计。 | [INC-009] |
| 教师 | 预览、换卷、选专项难度与组合出卷 | 发布前看完整题面，可换一套或修改设置再预览。任选两三类组成综合卷，尽量均分题量。专项卷也可分基础、提高，确认时固定最终题目和顺序。 | [INC-008] |
| 学生 | 错题本与独立订正 | 可查首次填错、漏答的原题，回看分步讲解和历次订正。20 以内一步加减法订正正确后可从结果或错题本换一道同类新题，保持运算和进退位特征。新题独立批改，原卷得分和原题订正次数保留。 | [INC-007]、[INC-014] |
| 教师 | 查看原卷、草稿及个人历史 | 可从成绩表点学生姓名看逐题原答和批改，草稿标为未交未评分。从学生名单可按北京时间发布日期、题型或知识点查该生的历史练习。 | [INC-006] |
| 教师 | 按班和发布日期看练习月历 | 可翻月、点日期、看当天每份作业的截止时间、已交人数、未交人数和均分，从成绩明细返回原日期。 | [INC-005] |
| 教师 | 批量导入与查找学生 | 可下载文本学号样例，导入 .xlsx 或 UTF-8 CSV。学号作为账号和初始密码，问题逐行反馈。当前班可按姓名或学号搜索。 | [INC-004] |
