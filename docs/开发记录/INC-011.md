# INC-011　作业草稿恢复

2026-11-26 · **开发已交付，技术复核通过，待师生试用**

## 原始开发提示词

> 收到学生反馈，作业写到一半遇上重新登录，刚填的答案就丢了。而且有时一道题填的有问题比如填的数字比较大，其他题也跟着不能保存。他们希望填好的答案能先存下来，离开时可以点“保存并离开”，下次用原账号回来接着写。

## 开发前状态

建档时审查仓库起点为 `88ad56e`，应用基线为 `46cf58f`。学生可以手动保存草稿，停笔后也会自动保存，离页时有未存修改只能取消或放弃。体验时，第 50 题填入越界值后，第 1 题的有效答案也没存上。另一页退出账号后，原页新填的答案在重登时丢失，先前存好的答案仍能找回。
