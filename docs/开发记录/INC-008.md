# INC-008　发布前预览、专项难度与组合出卷

2026-11-24 · **开发已交付，技术复核通过，待师生试用**

## 原始开发提示词

> 1、现在我得发出去才看得到整张卷。我想先预览，觉得不合适就换一套，或者改设置再看。点“确认发布”后，学生拿到的题目和顺序要跟我最后看到的一样。预览时学生还看不到这份作业。 迁过来的旧库里已经有一张叫 assignment_previews 的表，每位老师存一份预览，里面有预览编号、题目和最后发布的作业编号。我也想在这样的老班级里照常预览、换卷和确认发布，已经发过的卷还能照常看。
>
> 2、混合题已经有基础和提高了，我还想给加减、乘除专项卷选难度。比如基础加减先练不进退位，提高档能练进位和退位；乘除提高档想多练需要认真回忆口诀或反推的算式。继续用现有数值范围和整除规则，预览里能看出两档的区别。
>
> 3、我还想偶尔发一张综合练习，自己勾选加减、乘除、混合中的两三类，把总题量尽量均分。比如三类都选、总共 20 题，就出 7、7、6 题，预览时让我看到各类题数。若含混合题，还能选已学知识点。学生照常交一张卷，满分还是 100。
