# INC-013　优先显示快截止的作业

2026-11-26 · **已定稿，待转交**

## 原始开发提示词

> 收到学生反馈，点开“我的作业”，做完的和还要交的作业都排在一起，看不出现在还有哪些没做。他们希望把还能交的作业放在一起，留给自己时间最少的排在最前面。个人限时一到，学生首页和老师的成绩表里都能明显看到这份作业已经不能提交了。

## 开发前状态

建档时审查仓库起点为 `88ad56e`，应用基线为 `46cf58f`。学生首页按发布时间排列作业。学生停在首页跨过全班截止时间，卡片仍可能显示“开始作答”。对照一份个人限时 1 分钟的作业，学生到时后已不能交卷，教师重新打开成绩表仍只看到“草稿”。
