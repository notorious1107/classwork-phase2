# INC-003　个人作答限时、混合题难度与平行班

2026-11-24 建档。状态为**提示词草稿待转交**。审查仓库准备起点为 `d446e13`，应用基线为 `6c4d794`。

## 为什么做

**需求原话**

> 当个作业的限时这个需求要，提高混合运算难度要，平行班要，把这三个编辑成一份提示词，准备交付开发

现有发布页能设置全班统一截止时间。混合卷可生成 100 以内的四则运算，但教师无法按年级、知识点或难度选题。教师目前用一张名单统计全班。现状见[已实现需求表](../resource/requirements/已实现需求.md)，混合题中过于简单的实例见[INC-002 验收项 A2](INC-002.md#实现效果与验收)。

## 本轮目标和验收条件

以下是写进草稿的业务约定。个人时长从学生第一次点“开始作答”起连续计算，与统一截止时间取较早者。难度先在 100 以内用已学知识点和有意义的运算步骤体现。平行班支持同卷分别统计。

| 验收场景 | 操作与预期 |
| --- | --- |
| 不同学生的个人限时 | 给一份作业设 20 分钟。两名学生于 19:00 和 19:10 开始，各自看到剩余时间，分别在 19:20 和 19:30 到期。刷新和重新登录沿用第一次开始的时刻。 |
| 与统一截止配合 | 同一示例加上 19:25 截止，第二人只能做到 19:25。服务端在到点时停止接收首次交卷，仍可保存草稿，计为未交。留空个人时长的作业继续沿用原截止规则。 |
| 混合题按所学内容和难度生成 | 选择年级、该年级已学知识点和基础档，复算题面并核对运算范围。换成已学括号的提高档，检查括号与有效步骤确实影响解法，题面和答案一致。新题保持 100 以内整数、除法整除，排除乘 1、除 1、加减 0 或乘 0 等可跳过的步骤。历史卷仍能按原题查看、判分。 |
| 平行班的发布范围 | 一班、二班各建名单。只给一班发布时，仅一班学生能打开作业。将同一份练习发给两班，两班学生看到同一套题，教师能按班查看学生进度。原班的账号、作业、草稿和成绩继续可用。 |
| 分班统计 | 一班三人，两人分别得 80、100 分，一人只存草稿。一班应显示 2 已交、1 未交、均分 90。二班两人均未交，显示 0 已交、2 未交、均分暂无。切班后学生明细与各自人数一致。 |

## 实际发给 AI 的提示词

### 开发提示词草稿

> 1、现在我只能规定全班最晚几点交，做口算练习时，我还想给每个学生相同的作答时间。比如这份作业限时 20 分钟，小林 19:00 点“开始作答”，就能做到 19:20。小周 19:10 开始，就能做到 19:30。学生能看到还剩多久，刷新或重新登录也接着计时。如果我还设了 19:25 全班截止，小周就只能做到 19:25。到点还能存草稿，没交的仍算未交。平时的作业也可以不设限时。
>
> 2、现在的混合题有时看着有两步，像 `83 ÷ (83 × 1)`，其实一步就算完了。我想发混合作业时，能按年级选学生已经学过的知识点，再选“基础”或“提高”。比如刚学先乘除后加减，可以练 `24 ÷ 3 + 5`。学过括号后，提高题可以出 `(36 − 12) ÷ 4 + 7`。先沿用 100 以内、除法能整除的范围，靠运算顺序和实际要算的步数加难。新题里别用加 0、乘 1、除 1 这类凑步骤的写法。
>
> 3、我同时教两个平行班，系统里却只有一张学生名单。我想能建一班、二班，把学生放进对应班级。发作业时可以只选一班，也可以把同一套题发给两个班。只发给一班时，二班学生看不到这份作业。两个班都做时，我能切换班级，分别看谁交了、谁没交、每个人得几分和班级平均分。原来班里的账号、作业和成绩也要能接着用。
