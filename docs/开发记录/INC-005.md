# INC-005　班级作业日历

2026-11-24 · **草稿待转交**

## 原始开发提示词

> 我带两个班，现在要找“周二给一班布置了什么”，只能一份份翻列表。我想在教师端选个班，用月历看练习，能翻月份，也能点进某一天。作业按北京时间的发布日期放到日历里，截止时间另外显示。比如周二发了两份作业，其中一份周四截止，我希望周二能看到两份，每份旁边有本班已交人数、未交人数和平均分，没人交就显示“暂无均分”。点一份就进现在的成绩明细，切到二班就看二班的数据。
