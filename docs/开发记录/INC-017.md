# INC-017　导出本班作业成绩

2026-11-26 · **草稿待转交**

## 原始开发提示词

> 收到老师反馈，想把一次作业的成绩带去教研会，现在还得照着页面抄。他们希望能在成绩页直接导出当前班这次作业的成绩，用 Excel 打开就能用。学号开头的零要保留，交了白卷的记 0 分，没交的成绩留空。

## 开发前状态

建档时审查仓库起点为 `88ad56e`，应用基线为 `46cf58f`。教师可切换班级，在作业成绩表查看学号、提交状态和得分。体验时页面能区分已交 0 分和未交，也能保留名单学号 `00124` 的前导零。成绩页可查看和刷新，尚无导出入口。
