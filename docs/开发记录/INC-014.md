# INC-014　订正后再练一道同类题

2026-11-26 · **已定稿，待转交**

## 原始开发提示词

> 收到学生反馈，错题改对以后，点“再练一次”看到的还是刚做过的题。他们希望能换一道同类题，试试自己是不是真的会了。可以先从 20 以内加减法做起，比如订正了 `18 − 5`，就换一道数不同、同样不用退位的减法。

## 开发前状态

建档时审查仓库起点为 `88ad56e`，应用基线为 `46cf58f`。学生在错题本里把 `18 − 5` 订正为 `13` 后，可看到讲解和订正记录。“合上讲解，再练一次”会重新打开原题，当前没有从这道错题换一道同类题的入口。
