# INC-016　给选中的学生布置补练

2026-11-26 · **草稿待转交**

## 原始开发提示词

> 收到老师反馈，看班级常错题时，明明已经知道哪几个学生做错了，想给他们补几道同类题，还得回去重新选题，而且只能发给全班。老师希望能直接在这道错题下面选学生，看一眼生成的题目，就把补练发给选中的人。

## 开发前状态

建档时审查仓库起点为 `88ad56e`，应用基线为 `46cf58f`。教师可从常错题明细查看每名学生的首次原答，区分填错、漏答和未交。另开发布页可以选题型、难度并预览，接收对象只能按班勾选。
